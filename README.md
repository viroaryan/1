# Nirvana Browser — Official Website

> **Private. Fast. Beautiful.**
> The official open-source website for Nirvana Browser, an independent, privacy-first mobile browser engineered with Mozilla GeckoView 153.0.4.

## 🌟 Overview

Nirvana is an independent browser project built by a small team led by **Abhiraj Aryan**. It is crafted to deliver a calmer, faster, and more private mobile web experience on Android.

## 🚀 Key Features

- **GeckoView 153.0.4 Engine**: True rendering independence without Chromium / Blink monopoly.
- **Total Cookie Protection**: Partitioned cookie jars per site to block cross-site tracking.
- **Built-in uBlock Origin**: Native WebExtension integration for zero-ad, fast mobile browsing.
- **Thumb-Zone Ergonomics**: Configurable bottom address bar for easy one-handed reach.
- **Granular Data Purges**: Automatic deletion of cache, tabs, and cookies on quit.
- **Apple Minimalist UI**: Inter / SF Pro typography, solid static stability, zero-lag 60fps scrolling.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## 🚀 Vercel Deployment

This repository is pre-configured for seamless zero-configuration deployment on **Vercel**:
1. Connect this repository to your Vercel dashboard.
2. Framework Preset: **Next.js** (auto-detected).
3. Build Command: `npm run build` (or `next build`).

5. Click **Deploy**.
